# Sheila Annisa — Personal Portfolio

Website personal profile / portfolio profesional untuk **Sheila Annisa**, fresh graduate S1 Ekonomi yang berpengalaman di bidang administrasi, admin sales, e-commerce admin, fundraising, finance management, public relations, dan social media management.

## Highlights

- One-page responsive portfolio (mobile-first, 360px – 1440px+)
- Sticky top navigation dengan hamburger menu di mobile
- Section: Home, About, Experience, Education, Organizational, Skills, Portfolio, Achievement, Contact, Footer
- Tema visual: Modern Professional · Clean · Soft Feminine · Trustworthy · Growth-Oriented
- Color palette: Soft Emerald `#2F6F5E`, Warm Beige `#F3E8D6`, Ivory White `#FAF8F3`, Muted Gold `#C9A227`, Charcoal `#2B2B2B`
- Typography: Playfair Display (heading) + Inter (body)
- Animasi reveal halus, hover lift pada card, smooth scroll
- SEO meta + Open Graph + accessibility (skip link, alt text, kontras tinggi, focus-visible)

## Cara menjalankan

Cukup buka `index.html` di browser, atau jalankan static server lokal:

```bash
python3 -m http.server 8080
# buka http://localhost:8080
```

## Struktur

- `index.html` — markup seluruh section
- `styles.css` — design system & responsive layout
- `script.js` — mobile menu, sticky nav, reveal on scroll, contact form
